# v0.1.0 - Spread carry alpha
Date: 2026-01-24

## Highlights
- Implemented StockFuturesSpreadCarryAlpha strategy (floor + alpha early exit).
- Added analytics modules for dividends, spread, liquidity, floor rate, execution, costs, and alpha metrics.
- Updated pipeline and backtest to compute entry/exit cycles over contract life.
- Updated UI to show spread chart over contract life with entry/exit markers and trade summary.
- Added new tests and updated API contract tests.
- Updated architecture and acceptance docs.

## API/Data changes
- /api/top-pairs now returns spread_pct, rtc_pct, floor_rate_annual, score_floor, total_score, decision.
- /api/spread-series now returns spread_mid, spread_pct, entry_flag, exit_flag, trade_cycle, trade_return_pct.

## Config
- Added spread_carry_alpha section in configs/default.yaml.
- Added allowed_expiry_months and allowed_expiry_years filters.

## Testing
- pytest and playwright e2e pass.

## Notes
